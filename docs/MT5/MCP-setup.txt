安装
pip install metatrader-mcp-server


在 BeeBotOS 的 TOML 配置中添加 MCP 客户端配置
参考 docs/MT5/MCP-toml-config.md。

config/beebotos.toml 中已经保留了注释形式的 MT5 MCP server 示例。
实际使用时请复制到 config/local.toml 或取消注释后填入当前环境的登录账号、密码、券商服务器和 MT5 terminal64.exe 路径。

测试提示词

📊 阶段一：账户与行情查询（只读操作，安全无风险）
这部分主要测试 Agent 能否准确提取数据并展示给你。

“帮我总结一下当前交易账户的状态，包括余额、净值、已用保证金和可用预付款。”
“查询一下欧元兑美元 (EURUSD) 和英镑兑美元 (GBPUSD) 的实时买入价和卖出价。”
“现在黄金 (XAUUSD) 的价格是多少？请同时告诉我今天的最高价和最低价。”
“列出我目前所有正在持有的未平仓订单，告诉我它们的开仓价格、当前价格和浮动盈亏。”
“查看我的历史交易记录，找出最近一周内我盈利最多的一笔交易是哪一笔？”

🧠 阶段二：逻辑分析与条件判断（考验 Agent 的“脑子”）
这部分测试 Agent 是否能结合多个工具或进行简单的计算推理。

“对比一下 BTCUSD（比特币）和 ETHUSD（以太坊）当前的点差，哪个交易成本更低？”
“我现在的总浮亏是多少？如果超过 100 美元，请提醒我注意风险。”
“帮我分析一下，我持仓的所有订单中，哪一笔的亏损比例（相对于开仓价）最大？”
“现在美股开盘了吗？帮我查一下 US30（道琼斯指数）的当前报价。”

⚡ 阶段三：基础交易指令（写操作，请务必在模拟盘测试！）
这部分测试 Agent 调用下单工具的准确性，切记检查手数！

“以当前市价买入 0.01 手 EURUSD。”
“卖出 0.02 手黄金 (XAUUSD)，并把止损设置在当前价格的上方 5 美元处。”
“帮我在 1.0800 的位置挂一个买单，买入 0.01 手 GBPUSD，有效期到今天收盘。”
“取消我所有的挂单（Pending Orders），但不要平掉我的持仓订单。”

🔄 阶段四：批量管理与风控（高阶操作）
测试 Agent 处理复杂任务的能力。

“把我手里所有处于盈利状态的订单全部平仓落袋为安。”
“把所有亏损超过 10 美元的订单都平掉，其他的保留。”
“为我当前持有的每一笔多单（买入单），都在开仓价下方 200 个点的地方设置止损。”
“统计一下我今天一共下了多少单？胜率是多少？”

💡 测试小技巧
故意模糊提问：比如问“帮我买一点黄金”，看 Agent 是会反问你需要买多少手，还是会直接按默认最小手数（如 0.01）执行。优秀的 Agent 应该在涉及资金时向你确认具体参数。
追问上下文：先问“EURUSD 现在多少钱？”，等它回答后，接着问“那好，帮我买入 0.01 手”。测试它是否能记住上一轮的货币对信息。
观察工具调用过程：如果你在 Cursor 或 Claude Desktop 中测试，留意界面上的“Tool Use”或“MCP调用”提示。看看它调用的函数名和提取的参数（如 symbol: "EURUSD", volume: 0.01）是否完全正确。
